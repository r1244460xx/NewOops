# Mr. Oops!! (PONOS 經典極限迴避遊戲復刻版)

這是一款向 2011 年知名遊戲開發商 **PONOS** 經典人氣手遊《Mr. Oops!!》（ミスターウップス）致敬的現代 HTML5 網頁遊戲。

玩家將操控經典的火柴人角色 Mr. Oops，在懸浮的 6×6 方格擂台上，以極限反應閃避四面八方來襲的致命飛行道具！

---

## 遊戲特色

1. **經典 6×6 棋盤式舞台**：
   - 具有立體質感的 6×6 懸浮平台。
   - 經典火柴人主角：具備流暢的跳躍、驚恐表情反應、落腳微塵與陣亡演出。
2. **四大遊戲模式**：
   - 🪨 **慢速巨石 (ROCK)**：巨大岩石滾動碾壓，速度較慢但體積大，考驗走位佈局與冷靜閃避。
   - 💣 **中速砲彈 (CANNON)**：鐵球砲彈疾馳而過，伴隨煙霧軌跡，常雙向交叉齊發，考驗節奏感。
   - ⚡ **快速雷射 (LASER)**：預警紅線蓄力後瞬間貫穿整行或整列，極度考驗預判與瞬間反應！
   - 👑 **全明星大亂鬥 (ALL-STAR)**：巨石、砲彈、雷射混合登場，波次隨時間狂暴升級！
3. **經典要素與彩蛋**：
   - **紅色箭頭警示**：邊緣格子出現紅色驚嘆號 / 箭頭閃爍警示，預告即將出現的危險行/列。
   - **近距離閃避加分 (NEAR MISS!)**：在危險擦身而過的瞬間成功跳開獲得額外獎勵分數！
   - **金星道具 (STAR PICKUP)**：隨機在格子上出現的金色星星，冒險拾取可獲得大量額外分數。
   - **血腥模式切換 (Bloody Mode)**：致敬原作經典的 IAP 模式，開啟後擊中會有誇張滑稽的噴濺演出。
   - **純 Web Audio API 晶片音效與熱血 BGM**：無須任何外部音頻檔，即點即玩，支援一鍵靜音。
   - **本機最高紀錄儲存**：無需後端資料庫，自動在瀏覽器儲存各模式的歷史最佳成績。

## 操作指南

- **電腦操作**：
  - 移動：方向鍵（`↑` `↓` `←` `→`）或 `W` `A` `S` `D`
  - 暫停 / 繼續：`ESC` 或 `P`
  - 重新開始：`空白鍵 (Space)` 或 `Enter`
- **手機 / 平板觸控**：
  - **滑動（Flick / Swipe）**：在畫布上向任意方向滑動即可移動。
  - **螢幕虛擬按鈕（D-Pad）**：可隨時於主選單開啟或關閉下方十字鍵。

## 運行與數值後台 (邊玩邊調參數)

本專案支援將「**遊戲主畫面**」與「**參數設定後台**」在 Chrome 中開兩個分頁並排顯示，支援即時雙向連動，並可直接將參數寫入硬碟中的 `config.json`：

```bash
# 啟動專用本地伺服器（支援寫入 config.json 到硬碟）
python3 server.py 8081
```

接著在 Chrome 開啟以下兩個分頁並排：
1. **遊戲主畫面**：[http://localhost:8081/index.html](http://localhost:8081/index.html)
2. **參數設定後台**：[http://localhost:8081/settings.html](http://localhost:8081/settings.html)

### 參數後台特色：
- **滑桿 + 純數字輸入框**（支援 placeholder 預設提示）。
- **即時自動持久化**：拉動滑桿或修改數值後，秒級自動保存至硬碟 `config.json`，無需手動點擊「儲存」。
- **即時雙向連動 (Live Broadcast)**：在設定分頁微調時，遊戲分頁立即生效。
- **防止參數重置**：客製化版本保護，重新開局或再來一局絕不被預設值洗白。
- **等級波數升級制**：可設定每關需避開的波數（`wavesPerLevel`），避開指定波數即升級。
- **三模式獨立冷卻間隔**：巨石、砲彈、雷射各自具備獨立的發射間隔參數。
